cpp_function.cpp now emit recovered.cpp with shared per-expression functions,

The exporter re-reads saved C++ function bytes, parses every statement of the
restricted emitted subset, including return indices, and universally checks
them against the original expression. It does not substitute proof of an IR for
proof of the emitted function text. Reuse requires both generated code and the
original canonical expression, not just identical output code. Saved bindings,
function spans/hashes, runtime/source identities and UNSAT query identities are
recorded and checked by check_program_artifacts. Unsupported statements and
non-UNSAT results fail export. Runtime operation meanings, frame execution, the
C++ compiler and Boost remain trusted/tested code: this is not a general C++
verification or whole-device/schedule theorem. Original observed-control and
unresolved-order limitations remain in force.

analyze now runs SSE -> folding -> routing -> arithmetic -> export. The generated
program accepts JSON lines for metadata, initial RAM, individual kernels and
complete frames. Frame operands/results use unsigned decimal strings; RAM state
is 256 halfwords plus a held read value per instance. All port functions use old
RAM read states before any instance changes. Inputs include physical boundary
cuts and explicit clock edges. Accepted numeric permutations remain separate
annotations; executable equations retain raw physical coordinates.
