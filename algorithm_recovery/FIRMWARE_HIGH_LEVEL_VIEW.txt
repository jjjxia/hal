2. 实际恢复出来的行为

  手柄 DANA_module_0 的 8 位状态可读成下面的等价排版：
    if (c_b1756)                         // 异步复位
        DANA_module_0 = 0;
    else if (rising(c_b3) && c_b4847)     // 真实时钟与使能
        DANA_module_0 = (DANA_module_0 + 1) mod 256;
    else
        hold;

  头显 DANA_module_3 同样恢复为 8 位加一，实际条件为：
    异步复位 c_b1777；时钟 c_b3 上升沿；使能 c_b4356。
  c_b 名称保留物理网标识；对应的布尔函数在 control_kernels.h 中。
  这些计数器的业务用途尚未恢复，不能直接称为时间戳或定位控制。

  例如手柄 DANA_module_119 的完整数据表达式为 RAM g11007 的旧读锁存值；
  头显 DANA_module_122 对应 g11108。程序自行维护 RAM 数据和读锁存器，
  不从原始轨迹注入内部状态。两个固件各 21 个 RAM，均按 mode 0 的
  256 x 16、INIT、时钟、使能、位掩码和同事件先读后写语义执行。
  派生时钟/异步复位经过 delta 事件稳定化，超过 128 次显式报错。

  有条件的轨迹方程仍保留实际 guard；遇到未观察的分支，使用从原网表
  经 HAL SSE 提取并验证的无条件完整表达式，不能把未知分支猜成保持。
  未决位序组按物理位执行，没有因此删去状态。

5. 验证范围

  两份完整状态程序均从事件 0 连续执行全部 3072 个原门级事件，只有外部
  pad 刺激作为驱动，没有逐帧重置或轨迹内部状态回填。所有已知 FF、RAM
  读值、外部解析值、输出数据/使能/纯输出驱动及最终 RAM 内容均一致；
  最终回执中的 unobserved_output_fields 都为空。
  手柄比较 21299913 个已知 FF 位观察，头显 21521073 个；两份各比较
  1670896 个已知 RAM 读位观察和 86016 个最终 RAM 位。
  头显回执确认 2048 个提取事件与 1024 个未用于提取的事件全部通过。
  手柄导出早于提取窗口元数据功能，扩展观察后的回执不作该分类。

  原轨迹 X 单独计数；运行时明确选择初始未知 IO FF/RAM 读位的二态值，
  未知观察不作为已证明一致的位。新增输出观察严格保留全部旧观察和刺激。
  普遍成立的表达式证明 + 有限连续整机回放，是这里实际获得的保证。
  事件组合、运行时、C++ 编译器与前端语义仍属于信任/测试边界；尚无
  四态、模拟时序或无条件全域整机等价证明。论文构造案例的完整证书
  不会自动覆盖这些固件，也不能只凭 Coq 核心定理宣布集成已证明。
