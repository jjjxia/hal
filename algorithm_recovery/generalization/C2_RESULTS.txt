Concrete hwbfly storage reuse
  Source mpy_pipe_out -> anonymous w26 -> THREE recovered write nodes:
    w26 phase0: source-a=w20 phase2 delay1, source-b=w23 phase2 delay1;
    w26 phase1: source-a=w20 phase0 delay0, source-b=w23 phase0 delay0;
    w26 phase2: source-a=w20 phase1 delay0, source-b=w23 phase1 delay0.
  Independent source scoring identifies these as M2, M3 and M1 respectively:
    M1=cr*dr, M2=ci*di, M3=(cr+ci)*(dr+di).
  The phase0 edge crosses a sample boundary; collapsing every physical register
  into one logical value would lose precisely this distinction. M1/M2/M3 are
  scoring labels, not recognizer inputs or automatically inferred business names.
  This is the IMPLEMENTED three-product graph, not a four-product algebraic
  rewrite. The 13->11-bit slices, intermediate widths and round-to-nearest-even
  operations remain exact node functions. Identity normalization was not applied
  to the held-out module; its raw graph is what was scored and executed.

Controlled mechanism tests
  Two known registered graphs: coupled recurrences and an8-bit noncommutative
  graph with repeated operands, separate arithmetic shifts and modular overflow.
  Five implementations each: shared result register; separate result registers;
  extra idle slots; three-stage copy chains; removal of only identity-copy cuts.
  Factors4/7/8, all base-period origins, and supplied period multiples1/2/3 give186 graph
  representations. All186 pass structural and finite exact execution checks;
  all280 explicit retiming/unfolding coordinate comparisons pass.
  Supplying2P/3P is a representation test, NOT automatic period discovery or a
  period certificate. Recovery of original source structure is restricted to
  registered fixed bindings with retained compute boundaries and operand paths.

  Separately, a literal-copy normalizer reads the saved raw graph, identifies
  only same-width single-leaf identities, accumulates delays, and checks actual
  required prefix-history equalities before adopting the transformation.
  It saves the normalized graph before reading the oracle, then executes that
  graph using only external inputs and finite prefix history (no later-state
  injection). This normalization test uses only P and origin0, not all186 raw
  representations. All10 cases pass; the8 cross-implementation comparisons recover
  the same two-node core and end-of-sample output for each reference graph.
  Between0 and6 copies are removed, with0/2/6 required prefix equalities. Copy
  identities are syntactically checked; no new SMT/Coq proof is claimed. These
  copy chains remain within one base period; cumulative history beyond one
  sample is implemented but not exercised by this run.
  Intermediate physical-cycle outputs need not be equal across different
  schedules: cross-case comparison explicitly uses the final slot of each sample.
